### STEP 1: PROBLEM CLASSIFICATION
Identify what type of strategic question:
| Question Type | Signal Words | Core Tension |
|---------------|--------------|--------------|
| Prioritization | "which," "should I," "what first," "choose" | Resources vs. opportunities |
| Evaluation | "is this working," "should we continue," "what's wrong" | Investment vs. return |
| Response | "competitor did," "market shifted," "something changed" | React vs. stay course |
| Creation | "what should we make," "gaps," "need content" | Effort vs. impact |
| Process | "how do I," "workflow," "scale," "quality" | Efficiency vs. quality |
| Measurement | "how do I know," "metrics," "KPIs" | Signal vs. noise |
| Lifecycle | "refresh," "update," "old content," "retire" | Preserve vs. replace |
| Crisis | "not working," "negative," "failing," "respond to attack" | Contain vs. address |
State: "This is a [TYPE] question. The core tension is [X vs. Y]."

### STEP 2: CONTEXT EXTRACTION
From the question, extract:
**WHAT** is the specific decision or problem?
**WHO** is affected (which brand, which audience, which stakeholders)?
**WHEN** is this relevant (urgent, this quarter, long-term)?
**WHY** does this matter (what's at stake)?
**WHAT IF** we do nothing (default outcome)?
**Additional extraction based on modifiers:**
- Stage Modifier: What stage is the company? What are realistic capacity expectations?
- Lifecycle Modifier: What's the content's current performance? SEO equity?
- External Modifier: What specifically changed externally?
- Stakeholder Modifier: Who wants what? What are their real goals?

### STEP 4: OPTIONS GENERATION
Generate 3-4 distinct strategic options. For each:
**OPTION [A/B/C/D]: [Name]**
- Action: What we would do
- Assumption: What must be true for this to work
- Tradeoff: What we sacrifice
- Timeline: When we'd see results
**Required options by question type:**
| Question Type | Must Include |
|---------------|--------------|
| Prioritization | "Focus on X and defer Y" option |
| Evaluation | "Continue," "Modify," "Stop" options |
| Response | "Ignore," "Respond proportionally," "Respond aggressively" |
| Creation | "Create new," "Repurpose existing," "Don't create" |
| Process | "Systematize," "Keep ad-hoc," "Outsource" |
| Lifecycle | "Refresh," "Retire," "Replace," "Leave" |
| Crisis | "Ignore," "Monitor," "Indirect response," "Direct response" |
**Always force yourself to include:**
- One "do nothing / stay course" option (counter your action bias)
- One "investigate further before acting" option (if diagnosis uncertain)
- One option that questions fundamental assumptions

### STEP 5: DECISION FRAMEWORK
Build a decision framework specific to THIS question.
**Standard factors (adjust weights based on context):**
| Factor | Default Weight | When to Elevate |
|--------|----------------|-----------------|
| Revenue proximity | 2x | Always for revenue-stage companies |
| Time to results | 1x | Elevate if urgency high |
| Effort required (inverse) | 1x | Elevate if capacity constrained |
| Compounding potential | 2x | Elevate for long-term plays |
| Brand coherence | 1x | Elevate if brand at risk |
| Reversibility | 1x | Elevate for high-stakes decisions |
| Competitive differentiation | 1x | Elevate if market crowded |
**Add domain-specific factors based on question type:**
- Prioritization: Add "Opportunity cost" factor
- Lifecycle: Add "SEO equity preservation" and "Update effort vs. new creation" factors
- Format/Channel: Add "Audience presence" and "Sustainable resource" factors
- Measurement: Add "Actionability" and "Attribution clarity" factors
Score each option. State the winner clearly with reasoning.
