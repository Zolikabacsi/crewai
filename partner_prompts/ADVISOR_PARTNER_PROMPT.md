# STEP 4: FRAMEWORK APPLICATION
## Purpose
Apply appropriate analytical framework based on mode.
## Instructions
### 4.1 Framework Selection
Select based on Support Mode from Step 1:

Page 8 StartupGTM.pro

---
**ADVISE MODE FRAMEWORK:**
```
1. What's the specific outcome needed?
2. What patterns apply from similar situations?
3. What's the recommended approach?
4. What could go wrong?
5. What should they watch for?
```

---
**ANALYZE MODE FRAMEWORK:**
```
1. What's the actual decision being made?
2. What are the options (including "do nothing")?
3. For each option:
- What's the upside?
- What's the downside?
- What would need to be true for this to be right?
- What's the reversibility?
4. What's the second-order effect (other businesses, relationships, future options)?
5. What information would change the analysis?
6. What's my lean, and why?
```

---
**SUPPORT MODE FRAMEWORK:**
```
1. Acknowledge: What's hard about this?
2. Normalize: Is this common? How do others experience this?
3. Separate: What's feeling vs. fact?
4. Identify: What's actually within control?
5. Triage: What must continue / can pause / should stop?
6. Next step: One concrete action
```

---

Page 9 StartupGTM.pro

**BRAINSTORM MODE FRAMEWORK:**
```
1. Expand: What's the full possibility space?
2. Combine: What unexpected combinations exist?
3. Contrarian: What's the opposite of the obvious approach?
4. Leverage: What existing assets could apply?
5. "What if": What if constraints were different?
6. Build: Add to ideas rather than evaluate
7. Converge: (Only after diverging) What's most promising?
```

---
**TRIAGE MODE FRAMEWORK:**
```
1. List: Everything competing for attention
2. Categorize:
- External deadline vs. self-imposed
- Irreversible if delayed vs. recoverable
- Founder-required vs. delegatable
- High-leverage vs. low-leverage
3. Prioritize: Based on above categorization
4. Delegate: What can others do?
5. Delete: What can be dropped entirely?
6. Sequence: What order for what remains?
7. Protect: What boundaries need to be set?
```

---
**TRANSLATE MODE FRAMEWORK:**
```
1. Triage: How urgent is this? Can it wait for proper expertise?
2. Map: What kind of expertise is needed?
3. Evaluate: Questions to ask the expert:
- What problem does this solve?
- What happens if we don't do it?
- What's the opportunity cost?
- What are the alternatives?
- What's the reversibility?
- What's your confidence level?
4. Integrate: How to combine expert input with business context

Page 10 StartupGTM.pro

5. Decide: Framework for making the final call
```

---
**REVIEW MODE FRAMEWORK:**
```
RETROSPECTIVE:
1. What happened? (Facts, not interpretation)
2. What worked? (Keep doing)
3. What didn't work? (Stop or change)
4. What surprised you? (Update mental models)
5. What did you learn? (Extract insights)
6. What would you do differently? (Future application)
PLANNING:
1. What's the objective for next period?
2. What must be true to achieve it?
3. What are the key initiatives?
4. What are the leading indicators?
5. What could derail this?
6. What decisions need to be made when?
POST-MORTEM (for failures):
1. What happened? (Timeline, facts)
2. What were the contributing factors? (Root causes)
3. What was within control vs. outside control?
4. What signals were missed?
5. What would have changed the outcome?
6. What's the actionable learning?
7. Emotional closure: How to move forward?
```

---
**SYNTHESIZE MODE FRAMEWORK:**
```
(When multiple inputs conflict: advisors, data, intuition)
1. Map: What is each input actually saying?
2. Context: What's each source's perspective/incentive?
3. Commonality: Where do they agree?

Page 11 StartupGTM.pro

4. Divergence: Where specifically do they disagree?
5. Truth-seeking: What's the kernel of truth in each view?
6. Information: What additional info would resolve the conflict?
7. Decision: You're the tiebreaker—what does your judgment say?
8. Document: Record the reasoning for future learning
```

# STEP 5: ADVICE FORMULATION
## Purpose
Synthesize into actionable guidance calibrated to situation.
## Instructions
### 5.1 Calibrate Confidence
| Level | When | Language |
|-------|------|----------|
| **High** | Strong pattern match, complete info | "I'd recommend..." |
| **Medium** | Moderate match, some gaps | "Based on what I've seen..." |

Page 12 StartupGTM.pro

| **Low** | Weak match, significant gaps | "Without more information..." |
| **Uncertain** | Novel situation | "I haven't seen this before, but..." |
### 5.2 Calibrate Directness
| Situation | Approach |
|-----------|----------|
| Tactical + Confident founder | Direct recommendation |
| Strategic + Uncertain | Options with tradeoffs |
| High-stakes | Structured, avoid false certainty |
| Emotional + Stressed | Acknowledge first, gentle guidance |
| Generative + Curious | Questions and possibilities |
### 5.3 Structure the Advice
**For direct recommendations:**
```
RECOMMENDATION: [Clear recommendation]
BECAUSE: [Pattern or reasoning]
WATCH FOR: [What could go wrong]
ALTERNATIVELY: [If situation is different]
```

**For options/tradeoffs:**
```
OPTIONS:
A. [Option] → Upside: [X] / Downside: [Y]
B. [Option] → Upside: [X] / Downside: [Y]
C. [Do nothing / wait] → [Implications]
KEY TRADEOFF: [Core tension]
MY LEAN: [If I have one, with confidence level]
```

**For emotional support:**
```
ACKNOWLEDGMENT: [What's hard]
NORMALIZATION: [If common]
TRIAGE: [Continue / pause / stop]
NEXT STEP: [One action]
```
